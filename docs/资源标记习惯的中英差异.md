# 资源标记习惯的差异:中文圈与英文圈

整理资源(图片、视频、音频等)时,很多人习惯在文件夹或标题末尾加上【10P1V】这样的标记,说明资源里包含多少张图片、多少个视频。其中字母的含义大致是:

| 字母 | 含义 | 英文来源 |
|---|---|---|
| P | 图片 | Picture |
| V | 视频 | Video |
| A | 音频(较少见但有) | Audio |
| G | 图片(Graphics,更少见) | Graphics |

> 补充:压缩包一般不做此类计数标注。它是"容器"而非"内容类型",单字母标注没有形成惯例。若确需表达,通常写中文「压缩包×N」或 `[N ZIP]`。

本文对比中文圈与英文圈(并附日文圈)在使用这类标记时的书写习惯差异。

---

## 一、包裹符号:【】 vs []

### 中文圈:用全角角括号【】

中文资源圈(网盘、论坛、图包、同人资源)几乎统一使用 **【】** 包裹标记:

```
【10P1V】
【20P】
【8P2V】
```

原因:【】是 CJK 全角字符,中文输入法可一键打出,视觉醒目,能把标记与标题正文清晰地隔离开。

### 英文圈和韩国:不用【】,用方括号 []

【】在英文圈几乎没有存在感——它是非 ASCII 字符,英文键盘打不出来,在文件系统、下载工具、网页中也可能出现兼容问题。英文圈统一使用 **ASCII 方括号 [ ]**:

```
[10P+1V]
[10P] [1V]
```

韩国在资源标记方面倾向于英文圈的习惯，使用 []。

### 附:日文圈

日本其实是【】的"老家",日文输入法同样能一键打出。日本资源标题里【】很常见:

```
【10P】
【無修正】
```

所以严格说,【10P1V】这种写法在中、日两国都很自然,只有到了欧美才换成 []。

---

## 二、加号:+ 的有无

### 中文圈:主流不加号,直接连写

【10P1V】是最常见形态,数字+字母紧凑连排,多项直接挨着,中间没有 `+`、没有空格:

```
【10P1V】   ← 主流
【15P1V1A】 ← 多项同理
```

加号写法【10P+1V】也存在,但属于少数变体,多见于偏"规范化"的整理者。

### 英文圈:常见加号,延续"句子思维"

英文圈写 `[10P+1V]`,本质是在模拟一句完整的英文计数:

> 10 pictures **+** 1 video

加号是语言习惯投射到文件名里的结果。英文圈也并非统一带 +,实际能见到多种形态:

| 写法 | 说明 |
|---|---|
| `[10P+1V]` | 紧凑,模拟句子(常见) |
| `[10P] [1V]` | 各自独立方括号(也常见) |
| `[10P, 1V]` | 逗号分隔(少见) |
| `10 images + 1 video` | 直接写全称(发布页常见,文件名少见) |

### 为什么中日文不加号

1. **P、V 本身已是天然分隔符**。「10P1V」里,P 和 V 已经把两组计数切开,读起来零歧义,加号多余。
2. **【】已完成"隔离"任务**。标记整体被全角括号圈出,内部不需要再做视觉分层。
3. **书写惯性不同**。英文里 "10 pics + 1 video" 自然带加号(甚至 and);中日文对应表达是「图10张、视频1个」,用顿号/并列即可,不存在 `+` 的语法位置。

---

## 三、深层原因:两套标点体系

英文资源圈不只是 [ ] 与 + 的问题,而是有一套完整的"括号分工"约定(参考社区通行的 Manga Naming Scheme 等命名规范):

| 括号 | 英文圈含义 | 实例 |
|---|---|---|
| `[ ]` | 元数据 / 标签 | `[FooScans]`(汉化组)、`[Decensored]`、`[10P]` |
| `( )` | 补充说明 | `(v02)`(版本)、`(mag)`(杂志扫图) |
| `{ }` | 修订版本 | `{r0}`、`{v2}` |

英文圈的标点使用是"句子思维":括号内放标签、圆括号放说明、加号连接并列计数。中文圈则把标记整体放进一个全角括号里,内部靠字母天然分隔——简洁、视觉统一。

---

## 四、实用建议

- **在哪个圈层发布,就跟随哪个圈层的默认写法**,不必刻意混搭:
  - 中文 / 日文圈发布资源:用 `【10P1V】`(日文语境也可写作 `【10P1動画】`)
  - 英文平台(Reddit、Patreon、GitHub、国际网盘):用 `[10P+1V]` 或 `[10P] [1V]`
- 中文圈里写 `【10P+1V】` 不算错,但容易让人看出不是圈内常见写法;英文圈里写【】则对方可能直接无法输入或显示异常。
- 若你的资源会被中英两个圈子同时看到,可考虑中性写法:方括号 + 无加号(`[10P1V]`),或直接写全称文字。
